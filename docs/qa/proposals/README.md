# File / file-text comparison — historical rejected proposals

These are historical internal QA artifacts, not production SVGs or a public showcase. Each sheet compares the then-current `file` and `file-text` variants against a proposal at 16, 20, 24 and 32 px. The final catalog uses the separately approved Proposal E.

- [Proposal A](proposal-a.png) changes only `file-text` to three interior lines. At 16 px it remains too similar to the generic `file`, which already has two interior lines.
- [Proposal B](proposal-b.png) also makes generic `file` blank. The distinction is clearer, but its proposed filled file retains the current fold contour, whose cutout opens through the right edge. It cannot be approved as drawn.

The corresponding [A vector sheet](proposal-a.svg) and [B vector sheet](proposal-b.svg) preserve the rejected samples for audit history. Neither A nor B was applied. The final `file-text` geometry and its verification are documented in the [NI-02 final report](../NI-02-CORE-DISTRIBUTION-AND-CATALOG-QA.md).
